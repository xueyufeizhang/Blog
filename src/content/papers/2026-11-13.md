### Research synopsis

**English**

The paper presents MAPE, a framework that evolves complete memory programs for intelligent agents from minimal seeds using a standardized lifecycle interface and an iterative diagnosis–proposal loop. Experiments on LoCoMo and LongMemEval report up to 12% absolute accuracy gains over manually designed baselines at roughly 35% of the serving cost, and show transfer across serving backbones and benchmarks. Empirical analyses surface two recurring design patterns: retaining raw conversations as retrievable evidence, and composing retrieved evidence according to query intent. The authors also show that jointly optimizing serving cost and accuracy shifts computation from costly LLM-based memory construction toward selective query-time processing.

**中文**

论文提出了 MAPE 框架，通过规范化的生命周期接口和迭代的诊断–提议循环，从最小种子进化出完整的智能体记忆程序。作者在 LoCoMo 和 LongMemEval 上的实验报告了相比手工设计基线高达 12% 的绝对准确率提升，且服务成本约为基线的 35%，并展示了在不同 serving backbone 和基准间的迁移性。实证分析发现两类反复出现的设计模式：保留原始对话作为可检索证据，以及根据查询意图对检索到的证据进行组合。论文还表明在同时优化服务成本与准确率时，会将计算从高成本的 LLM 驱动记忆构建转移到有选择的查询时处理。

### Thesis relevance

**English**

Overlap: both work on intelligent agent memory design and aim to improve downstream QA accuracy and serving efficiency. Differences: MAPE focuses on automated program evolution to discover memory architectures and highlights evidence-retention and composition, whereas the thesis centers on incrementally assembled structured graph memory (knowledge-graph-like triples), graph traversal for multi-hop retrieval, and entity resolution. Complementarity: the discovered patterns (raw conversation retention and query-aware composition) could be incorporated into a graph memory pipeline to improve evidence richness and query-time composition without contradicting structured storage.

**中文**

重合点：两者都关注智能体记忆设计，并以提高下游问答准确率和服务效率为目标。差异：MAPE 侧重通过程序进化自动发现记忆体系结构，强调保留原始证据与证据组合；而本论文课题集中在增量构建的结构化图记忆（以知识图谱概念为准）、基于图的多跳检索与实体解析。互补性：MAPE 提出的方法模式（保留原始对话与查询感知的证据组合）可以被移植到图记忆流水线中，用以丰富证据并改善查询时的组合策略，且与结构化存储方法不冲突。

### Writing and related work

**English**

Position this paper as an automated-design complement to manual memory engineering: it supplies empirical design patterns and a cost-aware optimization perspective. When citing, emphasize its findings on raw-evidence retention and query-aware composition as potentially orthogonal mechanisms to structured graph storage and traversal.

**中文**

将该论文定位为对手工记忆工程的自动化设计补充：它提供了经验性设计模式和成本意识的优化视角。引用时可强调其关于保留原始证据与查询感知证据组合的发现，作为与结构化图存储与遍历正交的机制。

### Method and evaluation

**English**

Actionable ideas: transplant MAPE's composition module into the graph-memory pipeline to test whether composing retrieved graph paths and raw conversational snippets improves answer use. Evaluate on the MultiHop-RAG benchmark to measure effects on multi-hop retrieval accuracy and bridge-entity identification. Also measure serving-cost vs latency trade-offs and include explicit entity-resolution metrics to see interactions with program-evolved memory designs.

**中文**

可执行的想法：将 MAPE 的证据组合模块移植到图记忆流水线中，检验将检索到的图路径与原始对话片段组合后是否能提升答案可用性。在 MultiHop-RAG 基准上评估，以量化对多跳检索准确率和桥接实体识别的影响。同时测量服务成本与端到端延迟的权衡，并加入明确的实体解析评估指标以观察与程序进化记忆设计的相互作用。

### Future directions

**English**

Explore hybrid approaches that evolve memory-program components specifically for graph-structured storage and entity-resolution policies. Investigate whether MAPE-discovered modules can be adapted to optimize composition of multi-hop reasoning paths in a persistent graph memory.

**中文**

探索将程序进化出的记忆程序组件用于图结构存储与实体解析策略的混合方法。研究 MAPE 发现的模块能否适配并优化持久化图记忆中多跳推理路径的证据组合。
